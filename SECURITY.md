# Security policy

IR Stack opera con privilegi root e modifica audit rules, unità systemd e, se esplicitamente abilitato, firewall.

Per segnalare una vulnerabilità nel progetto, evitare issue pubbliche contenenti exploit o segreti reali. Aprire inizialmente una segnalazione privata al maintainer del repository.

Non inserire mai nei bug report:

- password SMTP;
- indirizzi IP amministrativi non destinati alla pubblicazione;
- log contenenti credenziali o token;
- chiavi private SSH.
